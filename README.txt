=========================================
 TFT リーダーボード
 cup 1.4 ― 2026-09-18
=========================================

ログイン → 大会のリーダーボード だけの、独立した仕組みです。
特定のコミュニティ名を入れていないので、どの大会・スクリムでも使えます。
ポータル版とは別フォルダに置いて使います。

HOME・LPランキング・メンバー紹介・予定表・先生スナップショット・
Discord自動投稿 は入っていません。


■ ファイル

   index.html   ★ 表紙＝使い方の案内ページ（ログイン不要で誰でも読めます）
   login.html   入口。合言葉 → Riot ID → Discord → 先生/生徒 → 入場
   board.html   大会ボード本体（組卓・出欠・順位入力・全体順位）
   admin.html   管理画面（管理者だけ）
   core.js      共通ロジック（大会に必要なぶんだけ／2947行 → 1269行）
   config.js    ★ あなた専用の設定
   ui.css       見た目
   assets/      アイコン画像
   favicon.ico


■ 画面のつながり

   index.html ──▶ login.html ──▶ board.html ──▶ admin.html（管理者のみ）
                                     ▲                │
                                     └────────────────┘

   index.html（＝フォルダのURLを開いたときに出る表紙）は
   上の3画面すべてのヘッダーに「使い方」ボタンとして置いてあります。
   ログイン不要なので、Discord に直接貼って
   「まずこれを読んで」と案内する使い方もできます。
   ログイン済みで開くと、ボタンが「〇〇 としてボードへ」に変わります。

   参加者に配るのは login.html のURLです。
   ?board=<大会ID> を付けると、その大会に直行します。

     例: https://mo10c.github.io/cup/login.html?board=cup-2026-11

   付けないと default という大会に入ります。


■ ★★ データは混ざりません（2重に分けています）

   ① ポータル版（クラウドハッシュテイル校）とは別

                     ポータル版              この版
     大会ボード      lboards            →   tboards
     大会の索引      lboard_index       →   tboard_index
     ローカル保存    mcclb2:...         →   mcccup:...
     ログイン情報    mcc-lb2-session    →   mcccup-session   ★1.4で分離
     下書き          mcc-lb2-draft      →   mcccup-draft     ★1.4で分離

     ★ 1.3 まではログイン情報のキーがポータル版と同じで、
       同じブラウザで両方を開くと上書きし合っていました。1.4 で直しています。
       （そのため 1.4 では全員が一度ログインし直しになります）

   ② 合言葉（グループ）ごとにも別

     合言葉を SHA-256 でハッシュにした先頭16桁が「グループキー」です。
     保存先の名前にこれが入るので、合言葉が違えば別世界になります。

       大会ボード    tboards/<グループキー>__<大会ID>
       大会の索引    tboard_index/g_<グループキー>
       ローカル保存  mcccup:<グループキー>:<大会ID>

     合言葉そのものはどこにも保存されません（ハッシュだけ）。

   config.js の collections で ① の名前を変えられます。


■ ★ 合言葉（グループ）― 1.4 から

   複数のコミュニティが同時に使っても参加者が混ざらないための仕組みです。
   ログインの STEP 1 で合言葉を入れます。

   ・同じ合言葉の人だけが同じ参加者一覧・同じ大会に集まります
   ・合言葉が違えば、参加者も大会も互いに見えません
   ・前後の空白／全角半角／大文字小文字のゆらぎは吸収します

   作り方
     ログイン画面でまだ無い合言葉を入れると「新しく作りますか？」と出ます。
     グループ名（例: 〇〇スクリム）を入れて作成。
     ★ 作った人が、そのグループの主催（管理者）になります。
       config.js の admins に載っていなくても、自分のグループは管理できます。

   参加者への配り方
     ボードの「共有」／管理画面の「参加者に配るURLをコピー」で出るURLには
     ?g=<グループキー> が付いています。これを開くと合言葉の入力なしで入れます。

       例: https://mo10c.github.io/cup/login.html?board=cup-2026-11&g=2828cd0e32858462

     グループキーはハッシュなので、URLを見ても合言葉そのものは分かりません。
     合言葉を伏せたまま参加してほしいときはURLを、
     口頭やDiscordで伝えたいときは合言葉を配ってください。

   注意
     ・合言葉は復元できません（保存していないため）。
       忘れたときは、誰かが持っている ?g= 付きURLから入ってください。
     ・URLが外部に流れると、その人も入れてしまいます。
       流出したら新しい合言葉でグループを作り直してください。


■ セットアップ（3つだけ）

  ① Firestore のルールに2行足す
     Firebase コンソール → Firestore → ルール

       rules_version = '2';
       service cloud.firestore {
         match /databases/{database}/documents {
           match /boards/{id}        { allow read, write: if true; }   // 既存
           match /board_index/{id}   { allow read, write: if true; }   // 既存
           match /lboards/{id}       { allow read, write: if true; }   // ポータル版
           match /lboard_index/{id}  { allow read, write: if true; }   // ポータル版
           match /tboards/{id}       { allow read, write: if true; }   // ★この版
           match /tboard_index/{id}  { allow read, write: if true; }   // ★この版
         }
       }

  ② Discord の Redirects に、このフォルダの login.html を足す
     Discord Developer Portal → OAuth2 → Redirects

     ※ Worker の RETURN_ORIGINS にオリジンが入っていれば、
       実際には Worker が戻り先を決めるので、
       同じオリジン（https://mo10c.github.io）なら追加は不要です。
       別ドメインに置く場合だけ、Worker の RETURN_ORIGINS に足してください。

     ※ この版は Discord から「表示名」と「アイコン」しか使いません。
       サーバーのロールは読みに行かないので、Bot の設定も
       参加者がサーバーに入っていることも不要です。

  ③ config.js の admins を確認
     いまは usernames: ["mo10c"] が入っています。
     ここが3つとも空だと「セットアップ中」とみなして全員が管理者になります。

   Worker（tft-riot-proxy）はいま動いているものをそのまま使うので、
   デプロイし直す必要はありません。


■ 使いかた

  0. login.html で合言葉を作る（作った人がそのグループの主催）
  1. admin.html を開く（主催だけ入れます）
  2. 「🗂 大会の管理」→「＋ 新しい大会を作る」で大会を作る
  3. 「🏆 この大会」で 大会名 / 試合数 / 卓数 / 公開範囲 を決める
  4. 下の「参加者に配るURLをコピー」で login.html のURLを配る（合言葉つき）
  5. 参加者がログインすると board.html の参加者バーに自動で並ぶ
  6. 管理者が組卓（ドラッグ＆ドロップ）→ 対戦 → 「📊 結果」で順位を入力
     （⚡自動取得で Riot の履歴から取ることもできます）
  7. 🏆 全体順位が累計ptで自動集計（1位8pt 〜 8位1pt）


■ 管理画面（admin.html）のタブ

   🏆 この大会    大会名 / 試合数 / 卓数 / 公開範囲
   👥 メンバー    表示名の固定・先生/生徒の変更・大会に参加・除名・ランク再取得
   🗂 大会の管理  大会の作成・切り替え・削除
   🔌 接続設定    Worker URL の上書き・接続テスト・/diag・保存先とグループの確認
   💾 データ      JSONバックアップ / 復元 / 順位のクリア


■ 権限

                                管理者   ふつうの人
   ボードの閲覧・全体順位          ○        ○
   ログイン時の自己登録            ○        ○
   自分の出欠チェック              ○        ○
   他人の出欠・一括操作            ○        ✗
   大会名・試合数・卓数の変更      ○        ✗
   組卓・順位入力・⚡自動取得      ○        ✗
   admin.html                     ○        ✗（ロック画面）

   ※ ボタンを隠すだけでなく core.js の中でも弾いています。
     ただし Firestore のルールは緩いままなので、
     ブラウザのコンソールから直接書き換えることは技術的には可能です。
     身内の大会なら実害はありませんが、外部に開く大会では注意してください。


■ ★ ロールは「先生 / 生徒」（1.3 から）

   Discord サーバーのロールは使いません。
   ログインの STEP 3 で本人が「先生」か「生徒」を選び、それがロール代わりになります。

     ・参加者バーの上の「立場:」で 先生 / 生徒 を絞り込める
     ・自動で組卓の「均等分散」「固める」で使える
     ・管理画面の「公開範囲」で どちらかだけ入場可 にできる

   中身の値は teacher（先生）/ student（生徒）です。config.js ではこの値を使います。

   間違えて選んだとき
     ・本人がログインし直して選び直す
     ・または主催が 管理画面 →「メンバー」→ その人の欄のプルダウンで変える
       （主催が変えると、本人が再ログインしても戻りません。
         戻したいときは同じプルダウンの「本人の選択にもどす」）

   config.js でできること（任意）

     roles.adminRoleIds: ["teacher"]
        → 先生は全員が管理者になります

     roles.staffRoleIds: ["teacher"]
        → 先生は「見るだけの人」になり、参加者・組卓・全体順位に入りません。
          出てもらうときは管理画面の「メンバー」で「大会に参加」をON。

     ※ 両方に ["teacher"] を入れないでください。
     いまはどちらも空なので、先生も生徒もふつうの参加者です。


■ 使い方ページ（index.html）

   はじめての人がこれだけ読めば参加できる案内ページです。
   フォルダのURL（例: https://mo10c.github.io/cup/）を開くとここが出ます。

     ・参加する人の5ステップ（合言葉 → Riot ID → Discord → 先生/生徒 → 入場）
     ・ボード画面の見かた（図で説明）
     ・主催する人の流れ（大会を作る → URLを配る → 組卓 → 順位入力）
     ・ポイント表（1位8pt 〜 8位1pt）
     ・誰が何をできるかの一覧
     ・よくある質問 8件

   文言を変えたいときは index.html を直接編集してください。
   ふつうのHTMLなので、文字を書き換えるだけで直せます。


■ 1.4 で変えたところ（合言葉でグループ分け）

   ・ログインに STEP 1「合言葉」を追加しました。
     同じ合言葉の人だけが同じボードに集まります。
   ・保存先の名前に合言葉のハッシュが入るので、
     複数グループが同時に使っても参加者が混ざりません。
   ・グループを作った人が、そのグループの主催になります。
   ・★ ログイン情報の保存キーを mcccup-session に変えました。
     これまではポータル版と同じ mcc-lb2-session を使っていたため、
     同じブラウザで両方を開くと上書きし合っていました。
     この変更で完全に分かれます（1.4 では一度ログインし直しになります）。
   ・共有URLに ?g=<グループキー> が付くようになりました。
   ・ヘッダーにグループ名を出すようにしました。

   Firestore のルールは 1.3 のままでOKです
   （tboards / tboard_index の下に文書が増えるだけです）。


■ 1.3 で変えたところ（ログインの中身）

   ・Discord から受け取るのを「表示名」と「アイコン」だけにしました。
     サーバーのロールは読みません（＝特定のサーバーに紐づきません）。
   ・代わりに ログインの STEP 3 で「先生 / 生徒」を選びます。
     これがロール代わりになり、絞り込み・自動組卓・公開範囲で使えます。
   ・管理画面の「メンバー」に 先生/生徒 のプルダウンを追加しました。
   ・公開範囲のロール選択が 先生 / 生徒 の2つだけになりました
     （ロールIDを貼る欄はなくなりました）。
   ・すでにログイン済みの人は、次に開いたときログイン画面に戻り、
     「先生 / 生徒」を選ぶだけで再入場できます（Riot と Discord は入ったまま）。

   ※ Discordのログイン画面に出るアプリ名だけは、Worker が使っている
     Discordアプリの名前です。変えたいときは新しいDiscordアプリを作って
     Worker の CLIENT_ID / CLIENT_SECRET を差し替えてください。


■ 1.2 で変えたところ（見た目だけ／色はそのまま）

   色（金〜橙・空の青・濃紺の文字）は1.1のままです。
   変えたのは「使い方」のほうです。

     ・文字の大きさと太さに段差をつけた（前は何でも太字で平坦だった）
     ・枠線を細く薄く、影は浮いているものにだけ（前は全部に枠＋影）
     ・余白を4pxの倍数にそろえ、角丸を「面は大きく・部品は小さく」に統一
     ・ヘッダーやタブのアイコンを絵文字から線画（SVG）に
     ・試合タブを1本のレールにまとめた
     ・空席を「点線の薄い枠」に（前は太い枠の箱で、埋まった席と同じ重さだった）
     ・スマホで 大会名／試合数／卓数 が1行ずつ並ぶようにした
     ・表紙（index.html）を追加

   直したのは ui.css と各HTMLの <style> だけで、
   core.js（動き）と config.js（設定）は触っていません。


■ 名前を変えたいとき

   「TFT リーダーボード」という表示名は、各HTMLの
     ・<title>
     ・ヘッダーの <h1> と .sub
   にあります。コミュニティ名を出したいときはここを書き換えてください。

   アイコン（六角形のマーク）は
     assets/mark.png      ヘッダー用
     assets/icon-192.png  スマホのホーム画面用
     assets/icon-512.png  同上（大）
     assets/apple-touch-icon.png
     favicon.ico          タブのアイコン
   を差し替えれば変わります。


■ ポータル版との違い

   ・Discordサーバーのロールを使わず、先生 / 生徒 を自分で選びます
   ・HOME が無く、ログインしたらそのまま大会ボードに入ります
   ・LPランキング / メンバー紹介 / 予定表 / 先生スナップショット は入っていません
   ・Discord への自動投稿はしません（Cron も使いません）
   ・core.js が 1269行（ポータル版は 2947行）
   ・特定のコミュニティ名・校章を使っていません
