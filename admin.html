使い方 ボード

大会名

ボードの上に出る名前です。

試合数と卓数

1卓は8人です。減らすと、その先の試合や卓に入っていた配置と順位は消えます。

公開範囲

ロールを指定すると、そのロールを持つ人だけが入場できます。管理者は常に入場できます。

メンバー 0人

ログインして入場した人がここに並びます。
・表示名を入れると、その人が再ログインしても名前が変わりません（空にすると解除）
・大会に参加… 運営ロールの人を参加者として扱いたいときにONにします
・除名すると席と順位からも外れます（また入場すれば戻ってきます）
Riot APIを人数ぶん呼ぶので少し時間がかかります

＋ 新しい大会を作る

大会ごとにボードを分けられます。作ると、その大会のIDが付いたURLができます。
参加者に配るのは login.html?board=<ID> です。
半角英数字とハイフン。空欄でOK

大会の一覧 —

「開く」で編集対象を切り替えます。削除は元に戻せません。

Worker URL

Riot API と Discord ログインの中継先です。ふだんは config.js の値を使います。 ここで入れると、このブラウザだけ一時的に上書きできます。

保存先

この版が読み書きしている場所です。ポータル版とは別になっています。

バックアップ

この大会のデータをJSONで書き出し／読み込みします。大会前に一度取っておくと安心です。

危険な操作

どちらも元に戻せません。先にバックアップを取ってください。
